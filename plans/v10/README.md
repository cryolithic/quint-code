# Haft10 alpha source contracts

This directory contains the selected product contracts and design decisions
used by the separate `haft10` alpha implementation. `CONTRACT.md` covers
carriers and relations; `RUNTIME-CONTRACT.md` covers effects, recovery and
idempotence; `B2-DESIGN-DECISIONS.md` records selected B2A deltas. The other
retained files give interface and migration context.

These are design carriers. The released alpha scope and observed limits are
summarized in [ALPHA.md](../../ALPHA.md). References inside the historical
contracts to other planning or review documents are provenance, not a claim
that those private working records are part of this public source integration.
